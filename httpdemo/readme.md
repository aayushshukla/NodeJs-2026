# Package.json

- file is the central config file used in node js projects.
- it have following roles
  - Dependency management
  - project metadata
  - script automation

# Node Project

    - npm init
    - npm init --y

# Run Node JS

- node filename
- npm start

# NPM Basic Commands

    -  npm install                            npm i
    -  npm install package                   npm i package - it will install latest version
    -  npm install package@version         npm i package@1.1.1
    -  npm install package@tag             npm i package@latest

    - npm install --save package

    - npm install --global package            npm i --g package  - install package globally on your system to use a cli tool

    - npm install --save-optional package       npm i --s-o packagename

    - npm install --force    install i --f                      force installtion
    -  ### clear install
         npm  ci

    npm uninstall packagename
    npm  uninstall -g package
